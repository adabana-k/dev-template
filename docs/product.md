# Product Goal
テンプレートの目的: 端末固有設定を減らし、日本語仕様から検証済みPRまで一貫して開発できる状態を提供する。
利用先アプリの目的: **未定義。初回の機能開発前に記入する。**

# Target User
テンプレート: 個人開発者と小規模チーム。利用先アプリの対象ユーザー: 未定義。

# User Problem
端末ごとの環境差分、AIに渡す仕様の散逸、検証コマンドの不統一。
利用先アプリのユーザー課題: 未定義。

# Value Proposition
GitHub内に仕様・コード・検証・開発ルールをまとめ、再開しやすい開発を提供する。
利用先アプリ固有の価値: 未定義。

# North Star Metric
テンプレート: 新規プロジェクトが初回のCI成功PRを人間レビュー後にマージできるまでの時間。
現状の計測値: 未計測。利用先アプリの中心指標は初回企画時に設定する。

# Product Principles
- ユーザーの問題を先に定義し、機能数を目的にしない。
- 小さなIssueで実装・検証・レビューする。
- 人間が優先順位とUX、最終仕様を判断する。
- PDF/MIDI/練習支援等は元仕様書の例であり、本テンプレートの機能要求ではない。

# Feature Evaluation
User Value / Development Cost / Technical Risk / Usage Frequency / Product Fitを各5段階で評価する。
価値・頻度・適合度は5が高い。コスト・リスクは5が重い。根拠と不確実性も記載する。
